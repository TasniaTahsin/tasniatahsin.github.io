Selected Projects

AI for High-Accuracy Bacterial Detection, Segmentation, and Classification
Computer Vision · Microscopy

Built an end-to-end pipeline that detects bacteria in microscopy images (YOLO-style detection), segments their shapes (U-Net with post-processing for instance masks), and classifies morphology (ResNet-based classifier) for automated quantitative analysis.

Wearable Microstrip Patch Antenna for Health Monitoring
RF / Antennas

Designed and simulated a ground-slotted rectangular microstrip patch antenna for wearable devices at 3.5–3.8 GHz in CST Studio Suite, comparing flexible substrates such as Polyethylene, RT Duroid, Teflon, and PDMS to balance gain, return loss, and mechanical flexibility.

Data-Driven ADHD Diagnosis: Comparative Analysis Using PSD and SVM
ML · Neuroimaging

Developed a power spectral density (PSD)–based feature extraction pipeline on fMRI data with SVM classification, showing that carefully selected compact feature sets can outperform large feature spaces for ADHD vs control discrimination.
