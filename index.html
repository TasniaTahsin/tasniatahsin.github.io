Design and Analysis of Microstrip Patch Antenna for Wearable Devices Using Different Substrates
2024
Tool: CST Studio Suite

Designed and simulated a ground-slotted rectangular microstrip patch antenna for wearable devices at 3.5–3.8 GHz. Compared flexible substrates such as Polyethylene, RT Duroid, Teflon, and PDMS to balance gain, return loss, and mechanical flexibility.

Data-Driven ADHD Diagnosis: A Comparative Analysis Using PSD and SVM
2024
Model: Support Vector Machine (SVM)

Developed a power spectral density (PSD)-based feature extraction pipeline on fMRI data with SVM classification. The analysis showed that carefully selected compact feature sets can outperform large feature spaces for ADHD versus control discrimination.
